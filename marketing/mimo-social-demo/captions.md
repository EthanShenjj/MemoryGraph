# Mimo / 小忆 · 发布配文

## 小红书（中文）

### 标题

我把散落的对话，做成了可检索的记忆

### 正文

最近，我一直在做一个有点偏执的小工具。

每天和 Codex 聊很多轮、开很多个任务之后，我总会遇到同一件事：

明明记得以前讨论过，甚至已经做过决定，但就是找不到那段对话了。

上周定过的规则在哪？
当时为什么选 A，没有选 B？
这个答案到底来自哪个任务？

问题不是没有答案，而是答案散落在不同对话里。

所以我开始一点点搓 **MemoryGraph**，想给 Codex 做一个真正属于项目的“记忆”。

现在，它已经可以：

🔍 搜索项目里不同任务的对话

🧾 打开匹配结果，看到上一条用户消息和原始回答

↩️ 从结果直接回到来源任务继续工作

🕸️ 查看明确分支、延续任务和内容关联

✅ 自己确认或拒绝哪些内容值得成为记忆

做到后面，我还给它做了一个蓝色的小向导，叫 **Mimo**，中文名“小忆”。

这个版本的 UI 也来回改了很多次。最开始我只想画一张任务关系图，后来发现图能看懂还不够：真正需要的是“搜一句话，就能回到当时的上下文”。所以我又补了检索、匹配原因、来源详情和记忆审核。

安装时也可以直接选择中文或 English，Dashboard 会使用对应语言，之后还能随时切换。

它现在已经能用了，但我还想让下一版从真实使用里继续长出来。

如果 Codex 真能替你记住一件事，**你最想让它记住什么？**

评论区告诉我，也许会出现在下一版里。
