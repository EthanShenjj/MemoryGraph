# Traceable Memory / 可追溯记忆

这套视觉把 MemoryGraph 视为一张安静、可信的工作台。画面使用瑞士国际主义的网格、细线和留白，强调信息的层级与来源，不用装饰性图形制造热闹。IKB 蓝既是产品色，也是「可点击、可追溯、可确认」的动作线索。

真实产品截图是每张图的证据主体。界面保持正视角和清晰比例，通过大面积截图、局部放大与编号说明，展示跨任务检索、来源详情、任务关系和语言选择。文案只解释截图中真实存在的能力。

Mimo（小忆）是记忆向导。它的圆润轮廓与界面的理性网格形成轻微张力，但只出现在封面、语言选择和结尾位置，负责建立识别度，不遮挡产品内容。它的蓝色与产品主色完全一致，让 IP 与功能属于同一套视觉语言。

中文小红书采用 3:4 的产品实机相册：标题与创作故事放在笔记正文，图片几乎完整交给真实页面，只留下极短的操作提示。封面直接展示 Dashboard，让读者先看到作品本身。英文 X 采用 16:9，更像产品发布的简洁演示，每张只保留一个结论，让截图承担主要叙事。

成品应呈现一种经过推敲的克制感：标题轻、标签重，线条精确，截图清楚，Mimo 有亲和力但不幼稚。用户在缩略图上先看到主张，打开后能立刻读懂界面中的真实功能。
